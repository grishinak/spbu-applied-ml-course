# spbu-applied-ml-course

Репозиторий для сдачи домашних заданий по курсу **«Прикладные задачи машинного обучения»** (7 семестр, 2026).

## Как устроен репозиторий

В ветке `main` находятся только общие файлы репозитория: `README.md`, `.gitignore` и `LICENSE`.

Каждое домашнее задание выполняется в отдельной ветке от `main`:
- ветка называется `hw<номер>_<тема>`, например `hw2_assessor_ratings_aggregation`;
- решение ДЗ лежит в этой ветке;
- готовое задание отправляется через Pull Request из ветки в `main`.
